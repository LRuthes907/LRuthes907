## 🚀 Projetos

### 🍕 DM-System — sistema de estoque e produção da Dany Massas
Sistema feito para uma fábrica de massas e pizzas de Canoinhas, em dupla com o [Bruno](https://github.com/BrunoGuttervill). Fui responsável pelo back-end e pelo banco de dados e integrei as telas em React à API.

- Login com JWT, senhas com bcrypt, recuperação de senha por e-mail e perfis de acesso (admin, operador e visualizador)
- Produção que desconta os insumos da receita e só confirma se houver estoque de todos
- Alertas de estoque baixo calculados em tempo real
